# V5 / V5.1 Residual-Shift Evidence Report

Date: 2026-09-16  
Scope: experimental evidence only

## Decision trail

- V5 binary residual-shift gate: **NO-GO** on the six-task screening Gate. The run was complete and its detector behavior was useful, but the strict mixed-shift no-worse criterion was not met.
- V5.1 residual-shift shrinkage: **GO** on the six-task screening Gate and the frozen 24-task confirmation. V5.1 is a post-hoc follow-up and does not overwrite the V5 decision.

## V5 binary Gate

Evidence: `residual_shift_gate/results/gate_20260916/`.

- `108/108` fits and `25,920/25,920` raw rows.
- Pure-label utility passed for `random_q05` and `smote_q05_k5`, but not all three methods.
- Residual detector behavior was strong: full six-task Gate mixed-shift rejection was approximately `99.5%`, while pure-label acceptance was approximately `61–65%` across methods.
- The strict pooled mixed-shift CI criterion was not satisfied; catastrophic-failure reduction could not rescue it because the six-task run had no task-level logloss delta above `1.0`.

## V5.1 shrinkage confirmation

Evidence: `residual_shift_gate/results/shrinkage_full_20260916/`.

Frozen policy:

`w = clip((0.75 - residual_auc)/(0.75 - 0.55), 0, 1)` and `p = (1-w)p_source + wp_consensus`.

The 24-task confirmation completed `720/720` fits and `216,000/216,000` raw metric rows. The task-cluster bootstrap used 10,000 replicates.

## Interpretation boundary

The supported result is a conditional deployment policy: when a target batch is close to the label-shift-compatible source geometry, continuous correction can preserve prior-shift utility; when residual feature separability is high, shrinkage approaches source calibration and limits practical risk. The result is not a new BBSE/EM estimator, not a real temporal-drift validation, and not evidence that SMOTE is universally beneficial.
